# simple-stats-measurement-calculator

A simple calculator to count and measure basic statistical data points.

## Description

Measurement Calculator is a basic Python-based tool designed to measure and calculate values from a dataset.

## Features

- Calculates the total sum of data items  
- Counts the number of data items  
- Measures the mean (average) of the dataset  
- Identifies the median value  

## Tech Stack

- Python
